# USMIND 思维导图 · 本地离线版（win/）

纯本地运行的思维导图桌面软件（Windows）。**无需联网、无需后端/数据库/账号**，数据保存在本机；保留脑图编辑、数学公式、附件媒体、主题系统、导入导出等核心能力。在线版（多端协作/分享/会员/管理后台）见仓库 `code/`。

---

## ✨ 功能特性

### 脑图编辑
- 双击编辑节点文字，`Ctrl+Enter` 强制换行，节点自动延伸。
- 右键菜单：字体颜色 / 背景颜色 / 复制 / 剪切 / 粘贴 / 删除 / 折叠 / 展开 / 插入数学公式 / 附件。
- 快捷键：`Ctrl+C / Ctrl+X / Ctrl+V / Delete`。
- **多画布（标签页）**：一个窗口打开多个导图，Tab 切换、新建、重命名、拖拽排序、删除；标签文字跟随节点实时更新。

### 数学公式
- 节点内插入 LaTeX 公式（KaTeX 渲染），支持矩阵、多行公式；双击公式节点进入编辑弹窗。
- 节点高度按公式实际尺寸自动计算，不塌陷；导出图片 / SVG 时公式完整显示。

### 附件与媒体节点
- 粘贴 / 上传图片、视频、音频、PDF、Office、代码文件等到节点。
- 图片、视频可作为节点主体平铺显示（超出裁剪）；附件自带别针标识。
- 双击附件节点内置预览与编辑：PDF（pdf.js）、图片、音视频、代码高亮（CodeMirror）、Markdown（marked）、Word（mammoth）、Excel（xlsx）。
- **外置附件模式（默认）**：媒体写入 `data\attachments\`，经虚拟主机 `https://media.local/` 流式加载，大视频不卡顿；`.usmind` 保存文件只含结构，小而快。

### 主题系统
- 内置多个诗意主题，支持自定义主题编辑：节点配色、分支彩虹配色、各层字号字体、画布背景色 / 背景图 / 背景视频 + 透明度。
- 设置即生效、关闭软件后保留；样式主题面板随时切换。

### 导入导出
- 导出：JSON（含全部标签页）、PNG / JPG / JPEG / SVG / PDF / Markdown；导出弹窗选择保存位置。
- **自包含 .usmind 包**：结构与全部媒体打成单个文件，双击直接打开，媒体自动恢复。
- JSON 导入：完整还原多标签页导图。

### 启动特效
- 开机画面：logo + 粒子环旋转 + 水波纹荡漾，背景与脑图主题色一致，2 秒后平滑进入主界面。

### 文件与保存
- `Ctrl+S` 保存：已有文件直接更新原文件（不弹窗、不加后缀）；新建文件首次选择保存位置。
- **自动保存**：编辑防抖自动落盘，刷新不丢。
- 双击 `.usmind` 文件直接打开；设置中可注册文件关联。
- 项目文件默认保存到 `C:\Users\<用户名>\usmind`（首次运行自动创建，可在设置中修改）。

### 画布交互
- Ctrl+滚轮缩放、底部/右侧细滑动条控制视口、按住根节点拖动画布。
- 多标签切换丝滑（渲染 loading 过渡）；画布背景图/视频铺满画布。

### 其它
- 所有弹窗按钮、滚动条、下拉框统一样式；右键不再弹出系统原生菜单。

## 快速开始

1. 解压 `release` 目录到任意位置（绿色便携，无需安装）。
2. 双击 `usmind.exe`。
3. 首次运行自动创建数据目录与默认保存目录（`C:\Users\<用户名>\usmind`）。

> 需要 WebView2 运行时（Win10/11 系统自带；旧系统请安装 WebView2 Runtime）。

---

## 目录结构

```
win/
├── src/                  C++ 壳程序（main.cpp 窗口+虚拟主机 / bridge.cpp 桥 / native.cpp 文件与安全）
├── web/                  前端（index.html、js/app.js、css/app.css、vendor/ 含 KaTeX/JSZip/CodeMirror/pdf.js/html2canvas 等）
├── build/                编译中间产物与测试脚本（build.ps1 产出 usmind.exe）
├── release/              发布目录：usmind.exe + WebView2Loader.dll + web/（整个目录拷走即用）
├── tools/                工具链（w64devkit、webview2-sdk）
└── build.ps1             一键构建
```

---

## 构建（开发者）

```bat
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物输出到 `release/`（绿色便携：复制整个 release 目录即可分发，无需安装）。

## 附件双模式

| 场景 | 推荐 |
| --- | --- |
| 日常编辑、大视频不卡 | 外置模式（默认） |
| 发给别人 / 换机器 | 自包含包导出（单个 .usmind） |

> 外置模式下 `.usmind` 文件本身不含媒体，只有结构；长期不用的大媒体建议删除附件节点以释放 `data\attachments\` 空间。

---

## 安全设计

- `safeRelPath`：写入附件路径必须是 `attachments/` 前缀、正斜杠、禁止 `..` 与 `:`（防目录穿越）。
- `media.local` 仅映射到 data 目录，其他路径不可达。
- 文件对话框打开附件：相对路径校验后才交系统打开。

---

## 常见问题

- **打开后提示缺 WebView2**：安装 WebView2 Runtime（Win10/11 一般自带）。
- **导出的 .usmind 双击是空白**：确认关联文件时以「打开方式」选择 `usmind.exe`，或在设置中注册文件关联。
- **其它电脑打开 .usmind 没内容**：用「自包含包」导出（媒体已打包）；普通保存的 `.usmind` 只含结构，需连同 `data\` 一起拷。
- **大视频卡顿**：外置模式下媒体不写入 json，流式加载，正常不卡；卡顿多为首次读取大文件。
