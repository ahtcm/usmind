# USMIND 项目需求文档（归档版）

> 来源：用户多轮需求确认（2026-09-25），含全部补充约束。

## 一、项目定位
对标 XMind 的全功能思维导图工具，架构为「本地 EXE 客户端 + 网页端编辑展示 + 无后端云端托管」：
- 用户仅运行本地 EXE（Windows），完成一次配置后通过网页端全流程编辑思维导图
- 文件自动同步至 Gitee/GitHub 仓库，触发 Netlify 静态部署
- 全程无后端运维成本

## 二、核心编辑功能（对标 XMind）
- 画布自由拖拽、缩放；节点跨层级拖拽重组
- 节点折叠/展开（单节点多级子内容一键收展）
- 右键菜单自定义操作
- 内容嵌入：纯文本、富文本、LaTeX、静态图片、GIF、音频、视频、外网超链接、HTML iframe
- 快捷键：Tab 建子节点、Enter 建同级节点、Ctrl+C/V 复制整棵子树、拖拽剪切迁移、Ctrl+Z 无限撤销（步数可自定义）

## 三、样式主题
- 全局：画布背景、线条样式/配色、框体主题
- 单节点：颜色、边框、样式独立设置
- 预制主题模板：多套配色/框体/连线主题一键切换

## 四、AI 辅助（双数据源可插拔）
- AI 创作：一键生成整图、节点拓展、空白主题搭框架
- AI 总结：整图/单节点/多节点归纳提炼
- AI 交互：节点问答、细节解读、优化、纠错、思路拓展
- 数据源 A：本地 Ollama（填地址，纯离线私有）
- 数据源 B：第三方 AI API（填接口地址 + 鉴权密钥）
- 可视化配置，按需启停

## 五、资源存储双模式
- 本地文件夹模式：资源存本地目录，编译时批量替换本地路径为线上 URL 前缀（前缀可配置）
- 私有 OSS 模式：填域名/密钥/上传路径，编辑即自动上传 OSS，本地预览直读在线链接；编译兜底上传未传资源并强制替换全部资源链接
- 全项目使用相对路径

## 六、云端同步与部署
- 手动保存 + 定时自动保存（间隔在 EXE 面板可设）
- 保存后自动编译静态项目 → 上传至配置的 Gitee/GitHub 仓库
- Netlify 等静态托管自动触发部署（仓库 webhook 机制）
- 线上反向导入：从已部署的公开地址拉取源码，本地生成可编辑工程，支持二次编辑再部署
- 当前阶段（未关联 Netlify 前）：静态文件复制到本地 nginx 站点（http://127.0.0.1:8866），git 推送到 gitee.com:carwang/usmind.git 测试

## 七、加密分享
- 网页端设置自定义访问密码，开启加密分享
- 编译时加密导图数据，未输密码者查看源码也无法窃取有效信息（AES 密文）
- 输对密码后展示与本地编辑完全一致

## 八、本地 EXE 客户端
- 无边框沉浸式 UI（无系统标题栏/无大条子，对标 XMind 薄工具栏风格）
- 唯一配置中枢：Github/Gitee 仓库地址（必填）、Ollama 地址/第三方 AI 密钥/OSS 参数（可插拔）
- 配置持久化到 EXE 同级 config 文件夹，复制 config 即迁移
- 自定义参数：自动保存间隔、最大撤销步数、线上资源 URL 前缀、AI/OSS 开关

## 九、目录规范（已确认）
```
usmind/
├── usmind/        # 静态部署根（git 仓库 gitee.com:carwang/usmind）
├── code/web/      # 脑图编辑前端源码
├── code/usmind/   # EXE 源码
├── script/        # bat + python 脚本（构建/启动/停止/重启/清库）
├── tools/         # 便携工具链（nginx-1.30.5 / node-v24.21.0 / python310）
├── logs/          # 日志与临时生成文件
└── docs/          # 文档
```

## 十、工具链与部署（已落地）
- nginx：tools/nginx-1.30.5，usmind 站点 8866 端口，root 相对路径 ../../usmind，motorlab 旧配置保留备份（conf/nginx.conf.motorlab.bak）
- Node v24.21.0、Python 3.10 均绿色便携版，脚本相对路径调用，不依赖系统 PATH
- 构建脚本自动安装缺失依赖（PyInstaller、npm 包）

## 十一、脚本清单
- build.bat：一键构建（前端编译 → 静态文件 → 打包 EXE）
- start.bat：启动 nginx + EXE
- stop.bat：关闭 EXE + nginx
- restart.bat：stop + start
- reset-libs.bat：清除依赖 + 重新下载依赖
- 其余可复用 Python 脚本（编译、上传、同步）随开发补充
